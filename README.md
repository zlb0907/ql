# 情侣同步观影应用

这是一个基于 Web 的情侣同步观影应用，允许情侣或朋友远程一起观看视频并实时同步播放进度。

## 功能特性

- 视频播放控制（播放/暂停、音量控制、进度条）
- 实时同步播放进度
- 聊天功能
- 弹幕系统
- 房间管理系统
- 响应式设计，支持移动端

## 技术栈

- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome 图标库
- Anime.js 动画库

## 部署

此应用可以直接通过 Netlify 或其他静态网站托管服务进行部署。

## 使用说明

1. 打开应用后，可以选择创建新房间或加入现有房间
2. 邀请伴侣通过房间 ID 加入
3. 上传或选择要观看的视频
4. 开始同步观影体验
